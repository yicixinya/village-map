# 乡情数字地图 · 使用说明

一个完全离线可用、扫码即开的 H5 乡情地图，包含地图标注、图文详情、AI智能讲解三大功能。

## 📁 文件结构

```
默认项目/
├── index.html      ← 主页面（双击打开即可运行）
├── data.js         ← 点位 + 村史数据 ★ 主要修改这个
├── config.js       ← AI 接口配置（API Key 等）
├── app.js          ← 程序逻辑（一般不用改）
├── style.css       ← 样式（一般不用改）
└── photos/         ← 照片文件夹（自己创建，放图片）
```

## 🚀 三步上手

### 第1步：体验效果
直接双击 `index.html`，用浏览器打开。
你现在看到的是**示例数据**（虚构的9处载体），可以点击地图标记、试用AI讲解。

> AI讲解默认未配置 Key，会提示报错——这是正常的，配好Key后就能对话。

### 第2步：填入真实数据
打开 `data.js`，按注释提示修改：
- `VILLAGE_INFO`：村庄名称、副标题、简介
- `MAP_CENTER` / `MAP_ZOOM`：地图初始中心和缩放
- `POINTS`：9处文化载体的真实数据（名称、经纬度、简介、图片）
- `VILLAGE_HISTORY`：把3万字村史访谈资料粘贴到这里

**怎么获取经纬度？**
1. 打开 https://gaode.com
2. 搜索你的点位地址，右键点击 → "这里是"
3. 显示 `经度,纬度`，**注意要调换顺序**填入（lat在前，lng在后）

### 第3步：配置AI讲解
打开 `config.js`，填入：
- `apiUrl`：你所用大模型的接口地址（已列出常用国产模型）
- `apiKey`：你的 API Key
- `model`：模型名（已列出常用选项）

> 推荐用 **智谱GLM-4-Flash**（注册送免费额度，glm.bigmodel.cn）
> 或 **DeepSeek**（很便宜，几毛钱能用很久）

## 📷 照片怎么放？

1. 在项目文件夹下新建 `photos` 文件夹
2. 把照片放进去（建议每张控制在 200KB 以内，手机加载快）
3. 在 `data.js` 每个点位的 `image` 字段填文件名，如 `"sushi_zongci.jpg"`

照片不用全部500张都放，每个点位挑3-5张代表性的就够了。

## 📱 答辩演示

### 手机扫码
1. 把整个文件夹放到任何能生成链接的地方：
   - 传到自己的服务器/博客空间
   - 用 GitHub Pages（免费）
   - 用腾讯云/CSS 静态托管
2. 生成二维码（草料二维码 https://cli.im 即可）
3. 扫码打开

### 投屏
直接用电脑浏览器打开 `index.html`，按 F11 全屏，投屏即可。

## ❓ 常见问题

**Q：AI讲解报错怎么办？**
检查 config.js 里的 Key 是否正确、接口地址是否匹配你用的模型。控制台（F12）能看到具体错误。

**Q：地图加载慢/白屏？**
data.js 里的瓦片源可能被限速。把 app.js 里注释的 OpenStreetMap 行启用、高德那行注释掉试试。

**Q：不用AI行不行？**
可以。AI部分不影响地图和图文展示。也可以把AI替换成"预设问答库"——在 data.js 里给每个点位写好问答，点击直接显示答案，不调API。需要我帮你改的话告诉我。

**Q：前端硬编码 API Key 安全吗？**
答辩演示完全没问题。如果要长期挂公网，建议：
- 用 Vercel/Cloudflare Workers 做个代理，把Key放服务端
- 或者限制 API 用量额度
